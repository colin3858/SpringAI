## 关于 API 的参数细节

#### #### 请求体（Body）与 URL 参数的区别是什么？

**答：**
 URL 参数一般用于 GET 请求中的查询字符串，格式如 `?key=value`；而请求体（Body）则主要用于 POST、PUT 请求中，用于提交结构化数据，如 JSON 格式的参数对象。

------

#### #### 如何定义一个参数是“必填”还是“可选”？

**答：**
 在 OpenAPI 或文档中，`required` 字段为 `true` 表示必填。调用时，如果漏填必填参数，接口通常会返回 400 错误。建议前端或调用方在提交前校验参数完整性。

------

#### #### 参数类型有什么要求吗？

**答：**
 是的，常见参数类型包括：

- `string`：字符串
- `integer`：整数
- `boolean`：布尔值
- `array`：数组

使用错误的类型会导致解析失败。传参时需严格按照接口文档定义的类型传递。

------

#### #### 怎么传递嵌套对象或数组类型的参数？

**答：**
 可以通过 JSON 结构传递嵌套对象。例如：

```
json复制编辑{
  "user": {
    "name": "张三",
    "roles": ["admin", "editor"]
  }
}
```

前提是接口参数支持对象结构并能被后端正确解析。

------

#### #### 参数校验失败会有什么提示？

**答：**
 接口通常返回 400 状态码，并在响应体中包含错误信息，例如：

```
json复制编辑{
  "code": 400,
  "message": "email 字段不能为空"
}
```

这类错误信息是前端调试的重要参考。
